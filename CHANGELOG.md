# Changelog

## 2.3.0 — 2026-11-05

**Важные дни**
- Свой цвет: рядом с готовыми цветами в окне «Отметить как важный…» есть палитра (`input type=color`). Значение проверяется строго как `#rrggbb`; цвет виден в кольце дня, подсветке подготовки и в «Ближайших». Правила CSS для своих цветов собираются только из проверенных значений и вставляются через `textContent`.

**Точки под днями**
- Убрана настройка «Слов на точку».
- Новая настройка «Что означают точки под днями» (Общие): выполненные задачи (по умолчанию: точка на задачу, до 5, закрашенная = выполнена), количество слов (фиксированные пороги 1 / 250 / 500 / 1000 / 2000), есть заметка, без точек.

**Прочее**
- Настройки: версия 4 (поле `wordsPerDot` удаляется при миграции, добавлено `dotsMode`).

## 2.2.0 — 2026-11-04

**Особые правила**
- Основной тип «Ежегодно» — день + месяц (без года), выбор двумя списками. Разовая дата с годом осталась как дополнительный тип, старые правила работают.
- Новые условия: диапазон дней месяца (в т.ч. через конец месяца), последние N дней месяца, первый/последний день месяца, начало/конец квартала, несколько дней недели в одном правиле (кнопки Пн–Пт / Сб–Вс), N-я неделя месяца, каждые N дней от даты, праздник из папки, важный день.
- Компактный выбор типа: список с группами (Даты / Месяц / Дни недели и циклы / Отметки).

**Календарь**
- Кнопка ⋯ теперь рядом с «‹ Today ›»; настройка положения (справа, слева, перед названием месяца, отдельной строкой).
- Быстрый переход: клик по названию месяца открывает окно с годом, сеткой месяцев и полем даты; режим «календарь / статистика».
- Папка праздников: даты в начале имени (DD.MM, DD-MM, DD/MM, MM-DD, YYYY-MM-DD, свой шаблон; разделитель после даты необязателен), настройка «сначала день / месяц», 🎉 в календаре, подсказка, меню с заметками; праздники в «Ближайших», правилах и статистике. Возраст показывается только для года ≥ 1900. Индекс кэшируется.

**Статистика**
- Переключатель «Таблица / Графики»: слова по дням, задачи выполнено/открыто, нарастающий итог (столбцы или линия), кольцо ✓ / без ✓ / без заметки. Выбор сохраняется.

**Исправлено**
- Цвета в палитре важного дня были серыми (стиль Obsidian `button:not(.clickable-icon)` перебивал фон). Выбранный цвет выделен кольцом; у цветов темы есть запасные значения.

**Прочее**
- Настройки: версия 3 (автоматическая миграция).
- Донат: https://donatre.github.io/; ссылка «Другие плагины» на https://nomberobsidian.github.io/.

## 2.1.0 — 2026-10-30

**Новое**
- «Применить шаблон»: кнопка **«Пропустить»** (вместо «Отмена», выбрана по умолчанию) — заметка не меняется.
- Массовое создание: существующие заметки всегда пропускаются, окно показывает их число; заметки создаются по одной, повторный запуск во время работы игнорируется.
- Статистика: **✓** у дня, где все задачи выполнены; в итогах — число таких дней и текущая серия ✓.
- Команды «Открыть предыдущую / следующую ежедневную заметку» (только существующие заметки), также в меню ⋯.
- Подстановка `{{carryover}}` — невыполненные задачи из предыдущей ежедневной заметки.

**Безопасность**
- Проверка путей: `..`, `C:`, `~`, управляющие символы, `.obsidian` блокируются при создании заметок и чтении шаблонов; предупреждение в настройках.
- Создание заметки больше не может перезаписать файл, появившийся во время чтения шаблона; параллельные создания одного пути объединяются.
- Валидация `data.json`: начало недели, локаль, слов на точку, условия правил, важные дни, лимиты длины и количества.
- Подстановки: значения вставляются буквально (`$&` и т. п. не интерпретируются); убрана регулярка с квадратичным временем в слиянии шаблона.
- Подсказка предпросмотра снимает свои слушатели; модальные окна закрываются при выгрузке плагина.
- rollup обновлён до 2.80.0 (GHSA-gcx4-mw62-g8wm).

**Код**
- Структура `core` (без Obsidian) / `io` / `ui`, модальные окна в `ui/modals`, меню в `ui/menus.ts`, `docs/ARCHITECTURE.md`.
- Удалён мёртвый код (`mockApp`, `__mocks__`, `fileMenu`, неиспользуемые константы, реэкспорты и строки), единый формат (prettier, ширина 100).
- Тесты: 100 (пути, валидация настроек, ReDoS, `{{carryover}}`, ✓/серия, соседние даты).

## 2.0.0 — 2026-10-30

**Ломающее изменение:** новый формат настроек (`settingsVersion: 2`) с автоматической миграцией из 1.x.

- Свои настройки ежедневных, недельных и месячных заметок (папка, формат, шаблон по умолчанию). Зависимость от Daily Notes / Periodic Notes и `obsidian-daily-notes-interface` удалена.
- Разовая миграция из 1.x (с переносом настроек Daily Notes / Periodic Notes) и кнопка «Импортировать из Daily Notes / Periodic Notes».
- Особые правила шаблонов: дата, ежегодная дата, диапазон, n-й/последний день недели месяца, чётная/нечётная ISO-неделя. Правила можно сортировать и отключать. Приоритет: правило → день недели → шаблон по умолчанию, с откатом при отсутствии файла.
- Правила применяются и к недельным/месячным заметкам (по первому дню периода).
- Команды: открыть вчерашнюю / сегодняшнюю / завтрашнюю заметку, недельную / месячную, создать недостающие заметки до конца недели / месяца (с окном подтверждения и итогом), применить шаблон к текущей заметке, важные дни, статистика, показать текущую заметку в календаре.
- Меню ⋯ в шапке календаря и контекстное меню заголовка месяца со всеми командами.
- Важные дни: название, цвет, дни подготовки; метки в календаре и блок «Ближайшие важные дни».
- Предпросмотр шаблона при наведении на пустой день.
- Окно статистики месяца (слова, задачи, важные дни, итоги).
- «Применить шаблон к существующей заметке»: дописать в конец / вставить в начало / заменить.
- Интерфейс на английском и русском (Auto / English / Русский).
- Стили переписаны на переменных темы; учтены мобильные устройства.
