# Changelog

## 2.12.0

- **Multi-range random daily note.** Settings → Random note and Go to date → Open random note support several period rows (all / year / month / last N days / custom range) with “+ Add range” and remove. The pick is uniform over the **union** of the ranges (duplicates removed). Skip empty unchanged. Legacy single-range prefs migrate (`settingsVersion` 12).
- **Dice quick-open.** Small 🎲 button next to “Open random note” in Go to date opens immediately with the **saved** ranges / skip-empty (no expand); closes the modal or shows a Notice. Equivalent ⋯ menu item “Open random note (saved settings)” (default **hidden**; enable in Settings → Menu). The existing command already used saved prefs — verified. Edits in the random block are persisted as you change them.
- **Organize settings layout.** The Organize button row no longer sits in a tall overflowing Setting control; buttons wrap in a plain `cwt-button-row` flex row. Same pattern for the random “Add range” row.

## 2.11.0

- **Daily note folders setting.** Dropdown “Daily note folders” (flat / by year / by year and month) is next to Organize. After Organize, “Also store new notes this way” is **on by default** so new notes (including at year boundaries, e.g. `2027-01-01` → `2027/01/`) match the layout you just applied. Old `yearFolders` still migrates to `folderLayout`.
- **Reverse organize.** Organize to flat, year, or year+month (settings buttons + commands, EN/RU). Preview, no overwrite, skip on conflict, undo. Optional removal of now-empty `YYYY` / `YYYY/MM` folders under the daily notes folder (shown in the preview).
- **Open statistics (Go to date).** No more Modal→Modal timing. “Open statistics” replaces the Go-to-date content **in the same modal** with the statistics panel; **← Back / Назад** restores Go to date (state kept). Standalone Stats modal/command for ⋯ and palette unchanged. Root cause of the unresponsive button: the closed random-note collapse (`grid-template-rows: 0fr`) still hit-tested over the mode row — fixed with `overflow: hidden` + `pointer-events: none` when closed. DOM tests cover click → stats and Back.

## 2.10.1

### Fixed
- **Upcoming filter menus stacked.** Each click on the filter button next to "Upcoming important days" opened a new Obsidian Menu without closing the previous one (`stopPropagation` blocked the usual outside-click dismiss). All plugin Menus now go through a shared exclusive helper: hide the previous Menu before opening, clear the ref on `onHide`, and toggle (second click while open closes) for the filter and ⋯ buttons. Same guard on day / holiday / week / upcoming-dismiss menus.
- **Go to date → Open statistics.** Choosing "Open statistics" then a month closed the navigator and opened Stats in the same click; Obsidian dismissed the new Modal immediately (`setTimeout(0)` was enough for Menu→Modal in 2.10.0, not for Modal→Modal). Month→stats now waits `MODAL_HANDOFF_MS` after close. Failures still show a Notice. Regression tests cover exclusive menus and the navigator mode/month wiring (mock DOM).

## 2.10.0

### Added
- **Create missing notes — week back / whole week.** New ⋯ menu items and commands: from start of week → anchor, and the full week. Confirmation modal unchanged. New items are hidden in the ⋯ menu by default (enable in Settings → Menu).
- **Organize by year and month.** Daily notes can live in `folder/YYYY/MM/note.md` (month = `01`…`12`). Setting **Daily note folders**: flat / by year / by year and month. Commands and settings buttons for both organize modes; undo still works. Path lookup finds notes in all three layouts (and mixed vaults).
- **Commands for every ⋯ / modal action.** All calendar actions are registered with `addCommand` (no default hotkeys) so you can assign hotkeys in Obsidian → Settings → Hotkeys. Includes: statistics, random note, go to date, create missing (week / week-back / week-full / month / displayed month), toggle holiday/important marks, settings, organize by year, organize by year-month, undo organize, important list, etc.

### Fixed
- **Open Statistics** from the ⋯ menu (and other Menu entry points) could fail silently because a Modal opened synchronously inside `Menu.onClick`. Opening is deferred one tick; failures show a Notice.
- **Upcoming header** no longer shifts vertically when expanding: the filter is absolutely positioned and compact (~20px), so the title and chevron stay put.

## 2.9.2

### Fixed
- **Upcoming filter clicks did nothing.** In 2.9.1 the native `<select>` lived inside a clickable `<summary>`; `preventDefault` on pointer events stopped the list from collapsing *and* blocked the browser dropdown. Replaced with a small button that opens an Obsidian menu (All / Holidays / Important days, check on the active one) and a visible chevron so it looks clickable. Filter clicks still do not toggle collapse.
- **Title “Upcoming important days” shifted** when expanding/collapsing: the disclosure triangle was a zero-size rotated border, so its footprint changed. Now a fixed 12px chevron box keeps the gap and title position stable; the filter stays right-aligned.

## 2.1.0 — 2026-10-30

**Новое**

- «Применить шаблон»: кнопка **«Пропустить»** (вместо «Отмена», выбрана по умолчанию) — заметка не меняется.
- Массовое создание: существующие заметки всегда пропускаются, окно показывает их число; заметки создаются по одной, повторный запуск во время работы игнорируется.
- Статистика: **✓** у дня, где все задачи выполнены; в итогах — число таких дней и текущая серия ✓.
- Команды «Открыть предыдущую / следующую ежедневную заметку» (только существующие заметки), также в меню ⋯.
- Подстановка `{{carryover}}` — невыполненные задачи из предыдущей ежедневной заметки.

**Безопасность**

- Проверка путей: `..`, `C:`, `~`, управляющие символы, `.obsidian` блокируются при создании заметок и чтении шаблонов; предупреждение в настройках.
- Создание заметки больше не может перезаписать файл, появившийся во время чтения шаблона; параллельные создания одного пути объединяются.
- Валидация `data.json`: начало недели, локаль, слов на точку, условия правил, важные дни, лимиты длины и количества.
- Подстановки: значения вставляются буквально (`$&` и т. п. не интерпретируются); убрана регулярка с квадратичным временем в слиянии шаблона.
- Подсказка предпросмотра снимает свои слушатели; модальные окна закрываются при выгрузке плагина.
- rollup обновлён до 2.80.0 (GHSA-gcx4-mw62-g8wm).

**Код**

- Структура `core` (без Obsidian) / `io` / `ui`, модальные окна в `ui/modals`, меню в `ui/menus.ts`, `docs/ARCHITECTURE.md`.
- Удалён мёртвый код (`mockApp`, `__mocks__`, `fileMenu`, неиспользуемые константы, реэкспорты и строки), единый формат (prettier, ширина 100).
- Тесты: 100 (пути, валидация настроек, ReDoS, `{{carryover}}`, ✓/серия, соседние даты).

## 2.0.0 — 2026-10-30

**Ломающее изменение:** новый формат настроек (`settingsVersion: 2`) с автоматической миграцией из 1.x.

- Свои настройки ежедневных, недельных и месячных заметок (папка, формат, шаблон по умолчанию). Зависимость от Daily Notes / Periodic Notes и `obsidian-daily-notes-interface` удалена.
- Разовая миграция из 1.x (с переносом настроек Daily Notes / Periodic Notes) и кнопка «Импортировать из Daily Notes / Periodic Notes».
- Особые правила шаблонов: дата, ежегодная дата, диапазон, n-й/последний день недели месяца, чётная/нечётная ISO-неделя. Правила можно сортировать и отключать. Приоритет: правило → день недели → шаблон по умолчанию, с откатом при отсутствии файла.
- Правила применяются и к недельным/месячным заметкам (по первому дню периода).
- Команды: открыть вчерашнюю / сегодняшнюю / завтрашнюю заметку, недельную / месячную, создать недостающие заметки до конца недели / месяца (с окном подтверждения и итогом), применить шаблон к текущей заметке, важные дни, статистика, показать текущую заметку в календаре.
- Меню ⋯ в шапке календаря и контекстное меню заголовка месяца со всеми командами.
- Важные дни: название, цвет, дни подготовки; метки в календаре и блок «Ближайшие важные дни».
- Предпросмотр шаблона при наведении на пустой день.
- Окно статистики месяца (слова, задачи, важные дни, итоги).
- «Применить шаблон к существующей заметке»: дописать в конец / вставить в начало / заменить.
- Интерфейс на английском и русском (Auto / English / Русский).
- Стили переписаны на переменных темы; учтены мобильные устройства.
